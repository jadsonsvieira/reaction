# ReAction - Release v0.1.26 (Sincronização Global do Tema Escuro/Claro em Todas as Abas + Novo Logo Instagram)

## Novidades e Ajustes (v0.1.26):

1. **Sincronização Global do Tema (Multi-Tab Global Theme Sync)**:
   - Padronizado a verificação de `reactionTheme` no `<head>` de todas as 7 abas internas antes da renderização.
   - Adicionado o listener `window.addEventListener('storage')` para atualizar instantaneamente o tema em todas as abas abertas simultaneamente quando o botão Lua/Sol é clicado.
2. **Atualização do Logo do Instagram**:
   - Atualizado o arquivo `static/img/plataformas/instagram.png` para a nova versão oficial enviada pelo usuário.
3. **Invalidação de Cache (`v=0.1.26`)**:
   - Queries de cache atualizadas em todos os templates HTML.
